cites the other, and the same publisher's 2027 page admits its numbers are
estimates. No traveller has reported paying 45,000 Ar at the gate.

are a rough guide, not an official rate.

### Photos you can get without a camera

Some slots are of public wildlife and landscape, not businesses — the lemurs, the
rainforest, the Namorona, the falls. Wikimedia Commons has genuine freely-licensed
photographs of those, and `scripts/fetch-photos.mjs` will find and download them:

```bash
npm run photos:find     # show what it would take, download nothing
npm run photos:fetch    # download the free-licensed ones
```

It only ever touches wildlife and landscape slots. It will not put a generic
rainforest photo on a hotel card, because that would misrepresent the hotel.

**It records attribution in `images/PHOTO-CREDITS.md`, and those credits must appear
on the site before you publish** — attribution is a licence condition, not a courtesy.
The script skips anything whose licence it cannot confirm as free for commercial use.

I could not run it from here (this sandbox blocks Wikimedia), so **run it once on your
own machine and check the results before trusting it**.
